# Chenxin Liu · 刘辰昕

Personal academic homepage: https://starsoul-ss.github.io/

Static HTML and CSS with local images and research demo videos. No build step or dependencies.

## Updating the site

- Edit `index.html` for the biography, publications, and links.
- Edit `styles.css` for the layout and appearance.
- Store photos, posters, and demo videos in `assets/`.
- Push to `main`; GitHub Pages publishes the repository root automatically.

Local preview:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```
